# Arc Raiders Hurricane Cache Overlay

Lightweight, safe, transparent overlay showing **possible** First Wave /
Hurricane stash spawn locations using static community data.

**Features** - Click-through transparent window always on top of the
game - Toggleable markers per map - Hotkeys (F8 toggle, F9 cycle maps,
etc.) - No memory reading, no injection --- 100% safe approach - Manual
calibration for alignment

Run with: `npm install && npm start`

Place your spawn JSON files in the /data/ folder.
