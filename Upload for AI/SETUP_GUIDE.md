1.  Install Node.js (LTS)
2.  Open terminal in the project folder
3.  Run: npm install
4.  Run: npm start

First launch: - Start Arc Raiders in borderless/windowed mode - Position
the overlay window over the game - Use the config UI (or edit
config.json) to adjust opacity and offsets - Calibrate by matching a
known in-game landmark to a marker

Hotkeys (in overlay window): - F8: Toggle visibility - F9: Next map
layer - F10: Reload data

For better integration, keep the overlay on a second monitor or use
window snapping initially.
