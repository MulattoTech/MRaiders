# MRaiders calibration guide

The earlier transparent Electron overlay is retained as historical reference
only. The native Qt companion aligns user-supplied, offline map images against
logical coordinates using tested two-/three-anchor transformations.

See [Native map calibration](docs/MAP_ALIGNMENT.md) for the workflow,
mathematical limits, testing and provenance considerations.

No game process access, live capture, or anti-cheat approval is implied.
