# Source and content provenance

Frozen Trail 2.0 released on October 8, 2026, confirmed by Embark:
https://id.embark.games/arc-raiders/support/faq/282-2-0-frozen-trail-update

New map Pendola Pass, Frigate and Redirection conditions, Bully/Skulker/Hydra,
Bantam/Stiletto, new Outpost, Weapon Stencils, Reward Pass and revised skills
appear in the official patch notes. The static progress checklist summarizes
selected high-level milestones, not the complete game database.

MetaForge product features were reviewed for **product inspiration only**:
https://metaforge.app/arc-raiders
https://metaforge.app/overlay
This repository does not include MetaForge map imagery, databases, proprietary
coordinates, commercial branding, or private APIs.

Original April 2026 starter marker files are retained as-is and carry broad,
unverified community-source descriptions. Treat as candidates, not verified facts.
The Pendola Pass, Stella Montis and Riven Tides datasets intentionally contain
zero markers. An empty file means 'unknown', not 'there are zero spawns'.
