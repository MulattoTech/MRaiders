# Security policy

MRaiders is a pre-release open-source-intended companion application.
Supported releases are not yet designated; source code is under active review.

Do not post exploit details, personal data or private tokens in a public issue.
Report vulnerabilities using GitHub private vulnerability reporting if enabled
in the repository security settings, or contact the owner privately through
their published GitHub contact channels.

Do not submit cheats, evasion mechanisms, process memory readers, packet
interceptors or game-input automation as security improvements. MRaiders
does not claim approval from Embark or guarantee anti-cheat compatibility.

Dependencies are watched with Dependabot, and the public Qt/C++ branch is
scanned by CodeQL through the checked-in GitHub workflow.
